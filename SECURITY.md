# Security policy

RIP Discord is a small hobby project, maintained on a best-effort basis. Only
the latest release gets fixes.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private reporting instead:
**Security** tab of this repository, then **Report a vulnerability**. Write in
English or French.

Please include the version, what an attacker needs (an invite code, being a
member, being on the same network…) and how to reproduce it.

## Known limits

The current security model and its known limits are described in the
[README](README.md#security). They are not secret and don't need a private
report.
